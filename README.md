# 島根県 転入超過・転出超過フロー

島根県を中心に、全国47都道府県との人口移動の純流動を可視化するWebアプリです。

## 内容

- 黒背景の日本地図風の簡易マップ
- 島根県の強調表示
- 青いドット：他都道府県から島根県への転入超過
- 赤いドット：島根県から他都道府県への転出超過
- 総務省統計局の2025年年報・月報（実数）に基づく都道府県間移動データ
- `net = inbound - outbound` による純流動の計算
- `net` の絶対値に応じたドット出現頻度
- 転入超過のみ / 転出超過のみ / 両方表示の切り替え
- 2025年1月〜12月の自動タイムライン表示
- 転出超過上位、転入超過上位のランキング

## 使い方

`index.html` をブラウザで開くだけで動きます。外部ライブラリやビルド作業は不要です。

## ローカルでの確認方法

1. このフォルダを開きます。
2. `index.html` をダブルクリックしてブラウザで開きます。
3. 画面上部のボタンで表示モードを切り替えます。
4. 2025年1月から12月まで、タイムラインが自動で進みます。

## 使用データ

データは `index.html` 内に直接書いてあります。

- `annualPrefectureData`: 2025年の年報表2から集計した年間合計
- `monthlyDatasets`: 2025年1月〜12月の月報表2から集計した月別データ

```js
{ name: "東京都", lat: 35.6762, lng: 139.6503, inbound: 802, outbound: 1079 }
```

`inbound` は各都道府県から島根県への転入者数、`outbound` は島根県から各都道府県への転出者数です。アプリ側で自動的に `net = inbound - outbound` を計算します。

公式表の読み取り条件:

- 使用表: 表番号2「移動前の住所地、男女別都道府県間移動者数」
- 使用区分: 国籍「移動者」、性別「総数」
- 読み方: 行を「移動前の住所地」、列を「移動後の住所地」として使用
- `inbound`: 各都道府県の行 × 島根県の列
- `outbound`: 島根県の行 × 各都道府県の列
- 検算: 月報12か月分の合計が年報表2の島根県の転入 10,419人、転出 12,140人と一致

出典:

- 総務省統計局「住民基本台帳人口移動報告」2025年（令和7年）年報（実数）表2
- 総務省統計局「住民基本台帳人口移動報告」月報 表2（統計表ID: 0003423613）
- 年報: https://www.e-stat.go.jp/stat-search/files?layout=datalist&lid=000001476215&page=1
- 月報DB: https://www.e-stat.go.jp/dbview?sid=0003423613

地図上の表示位置は、`mapPositionOverrides` で都道府県ごとの代表位置に補正しています。人口移動データだけを差し替える場合は、通常この補正テーブルは変更不要です。

## 地図データ

日本地図の輪郭は Wikimedia Commons の `Data:Japan.map` をもとに、試作品向けに軽量化して `index.html` に埋め込んでいます。

- 出典: https://commons.wikimedia.org/wiki/Data:Japan.map
- ライセンス: CC0-1.0

## 注記

この図は実際の移動経路ではなく、純流動を表現したものです。
